Aturan cetak/PDF

  1. Pilih A4 portrait dan skala 100%.
  2. Gunakan margin CSS 3 cm di semua sisi. Bila engine mengabaikannya, gunakan custom 30 mm dan periksa agar tidak ganda.
  3. Pastikan Cambria tersedia; fallback bukan pemenuhan Cambria persis.
  4. Default matikan header/footer bawaan browser. Footer dan nomor halaman bergantung pada engine; aktifkan hanya setelah hasilnya diperiksa.
  5. Periksa clipping, tabel, page break, blank page, diagram, dan font pada print preview serta PDF akhir.

Catat engine/versi, font aktual, mode footer, checks run dan limitations pada laporan akhir. Kerangka ini tidak menjamin hasil lintas browser.
